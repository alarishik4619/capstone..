URBAN MOBILITY VR LABORATORY - READY UNITY PROJECT

This is NOT an empty project. The included scene automatically builds a complete laboratory from Unity primitives when the scene opens.

Includes:
- Full enclosed laboratory room
- Large VR/city display screen
- City/road visual on the screen
- Four computer workstations with monitors, keyboards, desks and chairs
- Storage cabinets and plants
- KAT VR-style locomotion station
- Central road/test area with safety ring and lane markings
- Futuristic white passenger buggy with flat front
- Four wheels with rims
- Transparent windshield and side glass
- Seats, dashboard and steering wheel
- Headlights and tail lights
- Driver camera
- VR camera placeholder
- W/S/A/D and arrow-key vehicle movement
- Laboratory lighting

OPENING:
1. Open this folder as a Unity 2022.3 LTS project.
2. Open Assets/Scenes/UrbanMobilityVRLab.unity.
3. Wait a few seconds for the scene builder to finish. Objects will appear in the Scene view; no package download is required.
4. Press Play.
5. W/S or Up/Down = move. A/D or Left/Right = turn.
6. The Main Camera is placed in the driver area.

If the scene did not build automatically:
Unity menu -> Urban Mobility Lab -> Build Complete Laboratory

The project intentionally uses built-in Unity primitives so it is self-contained and does not become an empty scene because of missing external asset packages. Replace individual models later with commercial/FBX assets if desired.
